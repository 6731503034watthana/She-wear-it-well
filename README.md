# She wear it well — ระบบเช่าชุดออนไลน์

Next.js (หน้าเว็บ) + Flask (API) + SQLite (ฐานข้อมูล)

## วิธีรัน (เปิด 2 หน้าต่าง Terminal)

**1) Backend (Flask) — พอร์ต 5000**
```bash
cd backend
python -m pip install -r requirements.txt
python app.py
```
ครั้งแรกระบบจะสร้างไฟล์ `swiw.db` พร้อมบัญชีผู้ขายให้อัตโนมัติ (ไม่มีสินค้าตัวอย่าง ผู้ขายเพิ่มเอง)

เมื่อเปิดเว็บ (http://localhost:3000) จะเจอหน้าเลือกบทบาท: ผู้ซื้อ → `/shop`, ผู้ขาย → ล็อกอิน → `/seller`

**2) Frontend (Next.js) — พอร์ต 3000**
```bash
cd frontend
npm install
npm run dev
```
เปิด http://localhost:3000

## บัญชีผู้ขาย (สร้างอัตโนมัติ)
- อีเมล: `seller@swiw.com`
- รหัสผ่าน: `5555`

ผู้ซื้อกด "สมัครสมาชิก" ได้เอง

## ตั้งค่า (ตัวแปรแวดล้อมของ backend)
| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PROMPTPAY_ID` | `0999999999` | เบอร์พร้อมเพย์/เลขบัตรประชาชนของร้าน (ใช้สร้าง QR จ่ายเงิน) |
| `SELLER_EMAIL` / `SELLER_PASSWORD` | ดูด้านบน | บัญชีผู้ขายเริ่มต้น (มีผลตอนสร้าง DB ครั้งแรก) |
| `SECRET_KEY` | `dev-secret-change-me` | คีย์เซ็น token — **ต้องเปลี่ยนก่อนใช้งานจริง** |

ตัวอย่าง (PowerShell): `$env:PROMPTPAY_ID='0812345678'; python app.py`

## ฟีเจอร์
**ผู้ซื้อ:** สมัคร/ล็อกอิน • ดูสินค้าตามหมวด • ปฏิทินเช็กวันว่าง • ตะกร้า • QR พร้อมเพย์ตามยอดจริง • แนบสลิป • ดูและยกเลิกออเดอร์ (ก่อนตรวจสลิป)

**ผู้ขาย:** เพิ่ม/แก้ไข/ลบสินค้า พร้อมอัปโหลดรูปและตั้งราคาตามจำนวนวัน • เปิด-ปิดการเช่า • ดูสลิปและยืนยัน/ปฏิเสธออเดอร์ • อัปเดตสถานะ (ยืนยัน → จัดส่ง → ส่งมอบ → คืนชุด) • สรุปยอด

**ระบบ:** ราคาคำนวณที่ฝั่งเซิร์ฟเวอร์ • กันจองวันซ้ำด้วย transaction + unique key • ปฏิเสธ/ยกเลิกออเดอร์แล้วคืนวันว่างอัตโนมัติ

## โครงสร้าง
```
backend/app.py        API ทั้งหมด + สร้างตาราง SQLite
backend/uploads/      รูปสินค้าและสลิป
frontend/app/         หน้าเว็บ (/, /product/[id], /cart, /orders, /seller, /login, /register)
frontend/components/  Navbar, Calendar, OrderCard ฯลฯ
```

## ยังไม่ได้ทำ (แนะนำเฟสถัดไป)
ตรวจสลิปอัตโนมัติ • เงินมัดจำ/ค่าปรับคืนช้า • วันกันชนสำหรับซักชุด • แจ้งเตือน LINE • deploy จริง (ใช้ gunicorn/HTTPS, เปลี่ยน SECRET_KEY)
